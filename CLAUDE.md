# CLAUDE.md

## Start here

Read `agent-context/lib/index.md` at the start of every session. Then read every file the router points to for your task.

## Before writing code

Go (`apps/tools/`): read `agent-context/lib/developer-guide.md`.

Next.js (`apps/web/`): read `agent-context/lib/web-guide.md`. It names the few `developer-guide.md` sections that still apply; the rest is Go-specific.

## Before writing specs, docs, or comments

Read `agent-context/lib/style-guide.md`.

## Before writing tests

Read `agent-context/lib/testing-guide.md`.

## Before editing files in `apps/tools/internal/db/`

Read `agent-context/lib/developer-guide.md` §5.8 (Generated files). Never hand-edit sqlc output.
